# 独立生图工作室

此目录构建 `/image-studio/` 独立页面，保持原工作台和画布布局。主项目 `frontend` 执行 `npm run build` 或 `pnpm build` 时先构建本目录，然后将产物一起嵌入 Go 程序。安装后无需额外挂载页面或设置开发者站点地址。

- 标题、站名和 Logo 使用本站 `site_name`、`site_logo`；导航配置使用 `menu_visibility`。
- 默认 API 地址由浏览器当前 origin 生成，支持同一程序在不同域名/IP 和端口部署。
- 读取本站登录状态确认用户后才导入存储模块；凭据不会追加到跳转 URL。
- 生图、视频、图片素材和画布数据在本机浏览器保存，按当前用户隔离。不要删除旧页面的浏览器数据作为服务迁移步骤。
- 跨域参考图片由 `/api/v1/workspace/image` 提供登录鉴权、DNS 绑定校验和体积限制。
- `/image-studio/` 允许用户自写模型适配脚本，以及连接本地代理和本地 Agent；此页面的 CSP 扩展不影响控制台、登录页和教程。
- 可选的本地 Agent、代理或插件仍由使用者自行启动；默认不连接其他站长的服务。
