# OpenAI 档位与请求时区

## 档位配置

账号编辑的速度档位区支持 Fast、Ultrafast 开关，以及账号默认倍率和按模型单独倍率。未填写价格沿用既有模型或渠道规则。管理员覆盖直接作用于标准单价，覆盖输入、输出、缓存读取、缓存写入与长上下文费用，不重复叠加 Fast 溢价。

档位优先顺序：管理员分组强制设置 → 用户 API Key 强制设置 → 客户端请求。原有全局 Fast 策略仍可过滤、拒绝或重写最终档位。账号能力校验覆盖普通和高级调度、会话粘性、previous_response_id、HTTP、流式与 WS 的 response.create。普通档位及其他平台保持既有行为。

默认保留账号的两个档位支持状态。Astra Ultrafast 按 6 倍、6.1 Sol Ultrafast 按本项目约定的 8 倍作为模型默认，管理员可覆盖。倍率允许 4 位小数，范围 (0,1000]；模型精确规则先于通配规则，较具体通配优先。

用量记录保存档位和实际倍率快照。修改账号价格不改变已有记录。旧数据没有倍率快照时仅显示档位名。分组免费 Fast 的用户倍率显示 1 倍。API 上游降档不能使自定义档位的用户扣费反而变高。

## 请求时区

系统设置 → 网关 → OpenAI 请求时区提供自动识别开关与默认时区。账号默认选择「跟随网关设置」，可以显式选择 IANA 时区覆盖。原有手动配置保留。

自动模式只使用账号实际绑定代理的出口探测结果，不使用请求用户 IP 或服务器直连位置。仅接受合法 IANA 时区，不从多时区国家名称猜测。结果缓存 30 分钟，探测失败退避一分钟，最多两个后台探测并行；模型请求不等待地理位置网络查询。首次尚无识别结果、无代理、识别失败或缓存过期时使用网关默认时区。

代理路由缓存使用代理 URL 的 SHA-256 指纹作为内部键；账号换代理或代理地址、端口、认证变化后不会复用旧出口结果。指纹和代理凭据不进入模型请求或用户用量记录。

## 数据与验证

新增迁移 273，保存分组 Ultrafast 强制设置、API Key 档位偏好及用量倍率快照；认证缓存版本升级为 31。账号档位配置保存在 accounts.extra.openai_service_tiers。

本地验证覆盖策略优先级、账号选择和粘性排除、请求档位、Token 全费用项、免费 Fast、上游降档、余额预留、历史快照及 PostgreSQL 普通／批量／尽力写入。时区覆盖异步探测、代理变更、手动覆盖、失败回退和环境文本改写。没有调用真实付费上游账号。
