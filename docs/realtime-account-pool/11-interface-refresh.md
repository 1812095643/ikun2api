# 1.3.44 界面与读取异常调整

本轮范围按站点维护者 2026-11-05 的确认收窄为界面一致性、自动刷新、请求竞态和读取异常。原有用户字段、合成数值与状态、费用口径、可调度统计继续沿用；不执行此前讨论的稳定展示身份或用户字段裁剪重构。

`PoolView.vue` 仅保留页面外壳。号池功能位于 `components/pool`：Panel 组织页面，AccountTable 和 UsageTable 展示数据，RequestsDialog 独立管理账号请求生命周期，DisplaySettings 按需读写设置。沿用既有主题、表格、Select、Dialog 和分页组件。

`usePoolRequest` 通过 AbortController 与请求序号同时保护数据、错误和 finally。失败保留最近成功快照，切换账号、分页或筛选时清空旧范围数据。`usePoolRefresh` 在本轮完成后再排下一轮，页面隐藏或离线暂停、失败退避；打开设置或账号流水时暂缓背景轮询。

后端保留成功路径的统计公式。号池专用读取失败返回 `POOL_DATA_UNAVAILABLE`，展示策略四项一次读取，区分缺省设置与存储失败。公共账号统计服务的其它调用者保持既有行为。用户页面把读取失败显示为“网络异常”；该文案涵盖服务器读取依赖失败，不声称一定是浏览器断网。

账号资料库新增 `oauth_account` 与 `oauth_match` 只读字段。按主邮箱、平台和 `type=oauth` 匹配实时账号，排除软删除；来源优先级与账号管理邮箱一致，缺少邮箱元数据时只接受完整邮箱形式的账号名。唯一候选关联，无候选留空，多候选标记 ambiguous。原 `account_id` 手动关联和加密资料不被 GET 操作改写。
