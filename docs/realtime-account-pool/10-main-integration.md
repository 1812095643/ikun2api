## 入口与开关

- 管理端 `/admin/pool`、用户端 `/pool` 两个菜单均默认隐藏。
- 系统设置 → 菜单管理 → 搜索「实时号池」，可分别开启管理端和用户端入口，然后保存。
- 不在数据库初始化时写死为隐藏，不覆盖管理员后来保存的 true/false。
- 设置界面与导航使用同一个默认值函数，避免开关显示已打开而实际入口隐藏。
- 这是菜单显示开关，鉴权仍由路由守卫与后端中间件负责。
- 管理员访问自己的 `/pool` 也使用本人数据；只有 `/admin/pool` 使用全站视图。

## 名称展示

按站点所有者最新要求，用户端展示真实名称保留首尾、中间固定三个星号，
例如 `private-account@example.test` → `pri***nt@example.test`。
管理员保留完整名称；邮箱域名保留。

- OAuth 与 API Key 账号使用同一个遮挡函数。
- 既有用量接口和号池流水均在服务端遮挡，完整名称不下发给普通用户。
- 用量行保存真实历史快照，展示时遮挡，不修改历史原文；改名、删除后仍可辨认历史。
- 缺少快照的旧记录使用当前名称遮挡；账号已删除且无快照时才用匿名名称兜底。
- 用户搜索只匹配已展示的名称，不可用隐藏的中间文本探测原名。

## 查询与额度

- 用户端每次查询固定为登录用户；所有号池入口均拒绝其他 user_id。
- 用户端聚合接口沿用面板重查询限流；账号流水不提供写操作。
- 超大页码直接返回空页，避免整数溢出。
- 切换使用记录标签首次真实加载，支持刷新、共享 URL 与浏览器历史。
- 识别上游零利用率，拒绝 NaN/Infinity；过期周窗口不继续展示旧利用率。
- 管理员概览并发占用使用原有并发服务汇总。
