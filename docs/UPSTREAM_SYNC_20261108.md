本次基于 IKUN2api `c4cdb7e`（1.4.7）及本机尚未提交的智能路由、渠道状态、Unicode 改动，合入官方 Sub2API `v0.2.20`。官方发布于北京时间 2026-11-07 14:31:24，目标提交为 `dab829a4e9b7d1cc307189aea8b0319eb29e29d0`。未同步 tag 之后的 main，也未替换 IKUN 的发布仓库和版本号。

## 官方范围

- 管理 MCP：OAuth 授权、S256 PKCE、授权确认、连接管理、只读/写入和管理员权限、撤销、审计及限流。`MCP_PUBLIC_URL` 未配置时关闭。保持 IKUN2api 名称与原鉴权、二步验证、账本边界，MCP 菜单接入本站显隐及改名管理。
- 管理员 API Key：补全统计、OpenAI OAuth、邀请权限；全权兼容模式保留确认文字。新增邮箱精确黑名单，支持批量导入、Gmail 收件箱身份归一化和批量禁用。
- 资源治理：共享请求体缓冲预算、读取停滞超时、单次下游写入超时、取消后的有界 drain、后台通知队列与有界会话缓存；读取失败区分 408、499、413、解码错误与容量不足，日志不记录正文。安全默认预算 1 GiB、单次读写 120 秒，可配置 0 禁用；不把整个生成过程固定限制为 120 秒。
- OpenAI：1K/2K/4K 生图账号分流与粘性保护、GPT Image 2.6、原生编辑选项、传输冷却开关、空 instructions 兼容与原值回显、非流式终态/SSE 识别、强制协议免探测、WS 首 Token 与 HTTP 桥接修复。
- 模型与计费：完整 Terra Codex 元数据与 500k 默认窗口、effort 校验、缓存键、订阅长上下文计费；保留自定义模型与管理员定价。CC-Switch/手动 Codex 配置更新模型和联网/图片选项。
- Claude/Gemini/Antigravity/Grok/Kimi：setup-token 周窗口、长 cyber transcript、reasoning 累积、工具媒体、Gemini schema/SSE 上限、Antigravity 真正提示词测试/配额组/模型级冷却、Kimi 并发短冷却、Cloudflare REST beta 参数等修复。
- 导出与依赖：用量每页 1000 条和 429 Retry-After 重试，合入官方依赖安全补丁与部署配置说明。

## 与二开的组合

- 智能路由继续按候选组逐一鉴权、选号与计费；原始请求保留，分组尝试各自释放解码/补丁预算，避免额度在 failover 中累积。内存容量不足保留 503 与 Retry-After，超时与客户端断开保持专用分类。
- RPM 缓存同时记录“已确认无覆盖”的分组 ID。主组复用已确认快照，备用组独立查询；不能把主组覆盖误用于备用组，也不重复查询刚确认的空覆盖。认证快照升至 29，覆盖官方字段与智能路由字段。
- 记账继续使用本地必达任务；在异步任务提交前捕获渠道字段，避免复用 Gin context 后读取其他请求。通用订阅及异步任务归属仍使用本站账本。
- 保留 Claude 隐私允许列表、billing 清理、工具名可逆还原、思考签名恢复、遥测设置、设备身份与代理策略。官方测试中的额外转发头断言按现有隐私规则适配，Cloudflare URL 修复单独验证。
- WS HTTP 桥接使用既有 Codex 最终请求契约：收敛身份从连字符会话头与 turn metadata 验证，旧下划线/安装头仍按原规则清理。
- 保留 CC-Switch/Magpie 客户端选择、每个 Key 的合并模型目录、原生 Claude 默认行为与遥测关闭配置；不退回上游旧版写死的导入界面。CC-Switch 保留已验证的 TOML 导入契约并复用官方认证配置。
- Claude 的 UTF-16 字符语义、GPT 搜索兼容截断和普通 HTTP/WS UTF-8 JSON 正文边界保持不变。
