# 管理员账号资料库与自动热身

本功能仅在源码中合入，版本号保持 1.3.40。本次不创建版本标签、Release 或安装包，不部署 108。

## 账号资料库

入口为管理员「账号资料库」：支持分页、按平台/状态筛选、完整邮箱精确搜索、名称及标签搜索、增改、单条/批量删除。删除资料不会删除账号池账号。邮箱、密码、辅助资料、SessionKey、API Key、邮箱网址和备注存于经过认证加密的密文中；名称、标签和状态是列表索引元数据，请勿将密码放进名称/标签。

资料导入支持：

- 中文/英文标注的多行资料。
- 每行「主邮箱----邮箱密码----SessionKey----辅助邮箱----辅助密码」；缺项保留空列。
- 两列「邮箱----密码」。
- 带表头 CSV/TSV、JSON 对象/数组/items 包装。
- 自定义分隔列顺序：选择每列含义并预览。格式含糊时先修正，不猜测或静默丢弃。

默认掩码。逐格复制只按需读取该字段；短时查看在 60 秒或隐藏标签页时清除。编辑和查看敏感资料需要管理员真人会话和最近的 TOTP 二次验证，沿用 15 分钟验证窗口；普通管理员 API Key 不可读取。未启用 TOTP 时先到个人资料配置。敏感接口不缓存，审计保留操作与字段名称，不保存密码、Key 或导入原文。

重复导入默认跳过；可选择仅补空字段，或更新导入中的非空凭据。更新前重新校验版本，重复提交用批次 ID 去重。编辑器明确保存完整资料，允许管理员主动清空字段。

### 密钥与备份

资料库使用独立 AES-256-GCM 密钥、随机 nonce、记录身份认证数据及 HMAC 邮箱索引。

配置 ACCOUNT_VAULT_KEY_FILE 指向受限、持久保存的密钥文件。首次访问且库为空时创建；Linux 文件权限应为 0600。默认依次使用 DATA_DIR/account-vault.key、已有的工作目录 data/account-vault.key、工作目录 account-vault.key。Docker Compose 显式默认 /app/data/account-vault.key，使用已有持久卷。

**数据库备份不包含该文件。** 管理员必须单独备份密钥；多实例必须挂载同一份密钥。搬迁时同时恢复数据库和原密钥。已有密文但文件丢失时停止读写，不生成替代密钥。请勿提交密钥到 Git。密文使用 key ID 区分，当前版本不提供密钥轮换 UI；后续轮换需重加密全部记录。

## 自动热身

入口为管理员「自动热身」，提供规则、账号策略和执行记录。总开关及新建规则默认关闭。

1. 新建规则：选择全局/分组/指定账号，设置名称、套餐过滤和优先级。
2. 选择时区、星期、可选单次日期、一个或多个执行时段及轮数。跨午夜时段归属于开始日期的星期；重叠时段被拒绝。错过的轮次不补跑。
3. 选择当前模型列表中的 Claude 模型，设置每轮次数、消息/账号间隔、单次超时、每日上限、近期使用避让和活跃窗口跳过。
4. 预览影响账号与下次时间，启用规则及总开关。需要立即运行时，在预览中明确确认。

优先级数值大者优先；同优先级指定账号规则先于分组、分组先于全局。单账号排除/指定规则优先于继承规则。已知 429、停用、影子或非 Claude OAuth 账号跳过。

每轮先按顺序主动调用 OAuth 额度接口，**绕过成功缓存、错误缓存、被动采集和预测值**。任一五小时或周用量 **>99%** 跳过，恰好 99% 不触发该阈值。缺项、无权限、网络异常等不能当作 0%。多个候选账号先串行刷新再进入发送；轮到某账号时若快照超过一分钟，重新主动刷新。每条消息后重新刷新再决定下一条。

全站热身最多同时发送一条请求，通过 PostgreSQL 锁协调多实例。任务与旧定时测试共享账号锁，与在线业务共享并发服务；账号忙时本轮跳过。发送前再检查规则版本、账号状态、取消状态、每日请求上限，并先持久登记尝试。同一轮次唯一，崩溃后不重发不确定请求。

发送复用生产 Claude 构造、隐私过滤、账号身份、代理、TLS 和 OAuth 刷新链路；不是启动官方 CLI 进程。单次任务禁用额外重试，普通用户请求的原重试策略保留。发真实的 hi / hello 短消息，不用可被本地拦截的 max_tokens=1 探测作为成功证据。

记录显示主动额度、请求次数、Token、结果及上游确认的窗口时间。无可靠窗口头时显示“请求成功，窗口待确认”。运维请求不进入用户扣费、每日消费、签到或盲盒资格。

已有五小时窗口不能由再次请求任意重置，周限仍生效。真实 OAuth 的上游接受和窗口效果需要另行小范围验收；离线/本地模拟测试不能替代它。

## 菜单名称

系统设置 → 菜单管理，每个内置菜单可设置自定义名称、恢复单项或全部名称。空名称跟随系统多语言默认。父/子菜单、侧栏、移动导航、顶部标题、浏览器标签和顶部教程入口使用稳定菜单标识解析。名称不改变 URL 或权限；管理员专属名称不从公开设置下发。

原自定义菜单仍可在其原编辑器改名称。

## 验证边界

实现使用合成数据进行了导入、加密、授权、复制、额度阈值和调度回归，并在独立本机 PostgreSQL 验证迁移重复执行、导入幂等、旧版本冲突、删除隔离、串行额度预检及重复轮次。
界面验收使用本地合成 API 响应，覆盖资料库、五列导入预览及热身三步表单/结果展示。没有向真实上游发模型请求，也没有部署生产环境。
