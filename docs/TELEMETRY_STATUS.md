# 实验遥测状态

**当前状态：半成品，默认关闭，开发暂停。**

代码位于 `backend/internal/service/claude_telemetry.go`，配套离线测试位于同目录的 `claude_telemetry_test.go`。保留代码用于审阅和后续研究，本版不增加遥测功能，不启用线上上报。

现有实现只从网关实际转发的 Claude OAuth / setup-token 模型请求提取成功、失败、耗时、用量及关联身份，复用该模型请求的代理与 TLS 传输。请求头通过项目现有的大小写兼容读取方法获取，覆盖生产请求使用小写 `authorization` 的情况。

它不是官方客户端的完整生命周期实现。事件结构参考历史客户端样本；没有完成对应版本真实 OAuth 会话验收，也没有覆盖所有客户端启动、退出、交互和后台事件。

不生成虚构的项目维护活动、使用时长、国籍或地理位置。语言和时区属于真实运行环境配置，不能据此把遥测描述为“已经被认定是某国用户”。

保留既有开关键 `SUB6_CLAUDE_TELEMETRY_ENABLED`。未设置或不为字符串 `true` 时不会进入该实验队列。生产和示例配置均保持 `false`。离线测试只证明本地构造、选择与传输处理，不能证明供应商接收或账号安全。
