# IKUN2api

[![最新正式版](https://img.shields.io/github/v/release/1812095643/ikun2api?label=Release)](https://github.com/1812095643/ikun2api/releases/latest)

**基于 [Sub2API](https://github.com/Wei-Shaw/sub2api) 的 AI 网关与运营管理平台。**

支持 Claude、OpenAI / Codex、Gemini、Grok 等平台。在多账号、API Key、分组、计费与支付能力上，扩展用户工作台、账号维护、下游结算与链路诊断。后端使用 Go，前端使用 Vue 3，沿用 PostgreSQL 与 Redis。

[发布与下载](https://github.com/1812095643/ikun2api/releases/latest) · [新安装](deploy/README.md) · [带数据切换](deploy/MIGRATION.md) · [版本记录](changelog/)

## 相对 Sub2API 的主要扩展

持续合并上游修复，同时保留 IKUN2api 的协议处理、计费规则和原生页面。当前已合入 Sub2API **v0.2.24**；以下介绍本分支重点维护的新增功能与差异行为。

### 用户工作台与客户端接入

| 功能 | IKUN2api 的扩展 |
| --- | --- |
| **API Key 智能路由** | 一个 Key 可关联多个分组，配置有序备用分组，按模型与可用性路由；模型目录合并返回，客户端无需为每个分组分别配置 Key。 |
| **一键使用** | 在 Key 页面选择导入到 **CC-Switch** 或 **Magpie**，自动读取该 Key 可用的模型；保留手动导入。分组选择列表显示最近调价的涨跌与新分组标识。 |
| **模型广场** | 查看模型、可用分组、参考价与实付展示价，覆盖输入、输出、缓存读取、5m / 1h 缓存创建，以及按次、按张、按秒计价；支持人民币与美元展示。Claude / GPT 有已知原价时按原价展示，其他模型及无原价模型采用渠道价；展示规则与实际扣费配置分别管理。 |
| **实时号池与分享** | 展示开放分组内的 OAuth 号池、5h / 7d 用量百分比和并发，邮箱脱敏、隐藏具体金额。管理员配置可见分组，使用记录只展示访问者本人；支持带使用记录的只读分享链接、撤销及跨站自定义页面嵌入。 |
| **生图工作室与无限画布** | 内置独立生图工作室，支持图片生成、编辑及画布操作；补齐 base64 图片保存和结果读取，避免上游已生成、画布却取不到图片。 |
| **原生工单与运营页面** | 工单支持图片、未读筛选和管理员主动通知；内置教程、新闻、签到、盲盒、抽奖及窗口重置监控。抽奖可配置参与条件，并在保留已报名记录的情况下调整活动。 |

### 账号管理与请求调度

| 功能 | IKUN2api 的扩展 |
| --- | --- |
| **Claude 调度优化** | Anthropic 分组可开启「7d 时间临近优先调度」，窗口越临近刷新，调度权重越高；Claude OAuth 新会话结合额度水位选号，热会话结合缓存与排队压力决定等待或换号，保留限流、并发与会话绑定约束。 |
| **模型白名单与独立冷却** | 在选号和上游转发前校验账号模型资格，GPT WebSocket 每轮重新检查；上游明确返回模型不存在或过载时，可只冷却该账号的相应模型，其他模型继续使用，到期恢复。 |
| **OpenAI WebSocket** | 新建 OAuth 账号默认采用 WS 连接池与预热，保留显式关闭和强制 HTTP 设置；维持账号隔离、会话续接及 HTTP / SSE 客户端兼容。API Key 账号保留独立配置。 |
| **Fast / Ultra Fast** | OpenAI OAuth 与 API Key 账号可配置档位支持及倍率，并按模型覆盖；分组与用户自己的 Key 可强制选择档位，分组策略优先。使用记录显示实际档位和计费倍率，历史账单保留当时的规则。 |
| **代理故障保护与时区** | 绑定代理异常时暂停相关账号，恢复探测通过后再调度，并支持管理员手动恢复；代理故障不回退直连。请求时区可跟随代理出口，支持系统默认值和账号手动覆盖。 |
| **账号资料库与失效重登** | 集中管理、批量导入登录资料，并与 OAuth 账号关联；提供二次验证保护。失效重登支持查看、补充、编辑资料及单条操作，默认设置复用账号编辑的模型和分组组件，自动剔除已删除分组。 |
| **订阅标识与定时启停** | Claude OAuth 可手动选择订阅档位标识或恢复自动识别；账号支持定时及周期性启停，继续遵守账号健康、冷却和并发限制。 |
| **Claude 协议兼容** | 完善 Messages / Responses 转换中的思考签名保留；API Key 账号遇到明确的历史 thinking 签名错误时，可在同账号上清理相关历史并仅重试一次。 |

### 计费与站点运营

| 功能 | IKUN2api 的扩展 |
| --- | --- |
| **通用订阅** | 提供通用订阅管理、额度预留与结算账本，支持套餐配置和管理员调整，并保留重复请求的结算保护。 |
| **下游管理** | 标记下游用户，集中查看用量、充值和调价；复用每个用户已有的分组专属倍率，直接对照公开倍率修改，支持批量操作、列表排序及限制下游只能充值、不能购买订阅。 |
| **渠道定价联动** | 渠道模型价格可选择是否对下游生效，联动扣费、额度预留与展示；Fast / Ultra Fast 可配置独立倍率，账号和模型的显式设置优先。 |
| **记账收款** | 充值时可勾选「记账跑付」，先给额度、后登记收款；支持手动补记、部分收款、结清、备注、经办人与往来流水，收款和补记均不重复增加余额。 |
| **支付管理** | 扩展支付概览的统计维度；支付宝、微信可分别配置手续费，订单保留创建时的费率。 |
| **上游余额与告警** | 集中查看余额；同一上游多个 Key 的同口径读数不一致时显示最低有效值，支持排序、显示偏好，以及批量设置余额阈值、检查间隔和通知邮箱。 |

### 诊断、审计与隐私处理

| 功能 | IKUN2api 的扩展 |
| --- | --- |
| **原生连接诊断** | 在后台按请求查看鉴权、路由、连接、上游首响应、首个有效输出等阶段，区分客户端取消、连接失败和流式中断。使用 Go 有界队列异步批量写入，按时间分区及游标查询；正常请求保存摘要，异常、慢请求和少量成功样本保留详情。 |
| **内容审计** | 支持内容规则、审核记录与风控联动；优化 TypeSafe / Jev 对正常账号配置、运维与安全防护文本的误判，并按策略隔离、过期清理缓存，避免旧规则结果持续生效。 |
| **请求审计与使用记录** | 请求正文采用冷存储与历史增量保存，长会话按窗口读取；使用记录可自选筛选框与列，提供模型、推理强度、端点、分组、Token、首字与总耗时。异常高于 3000 tok/s 的记录改用总耗时重算，管理员可从邮箱菜单快捷筛选、查看充值或发送工单通知。 |
| **Claude 请求隐私过滤** | 清理已识别的客户端附加账单、网关与目录信息，保留正常对话需要的 system、工具和安全指导；原始客户端遥测在网关终止，脱敏摘要发送由系统设置控制，过滤不依赖发送开关。 |
| **IKUN Bridge 客户端与准入** | 提供 Windows／macOS Tauri 客户端，自动配置 Claude Code／Desktop、本地代理与隐私过滤，支持撤销和托盘运行；[源码、使用与打包说明](apps/ikun-bridge/README.md)。Anthropic 分组可开启「仅允许 IKUN Bridge」，沿用现有 Key 自动领证，在账号调度前校验。 |

## 从 Sub2API 带数据切换

在原服务器执行；Compose 部署先进入原部署目录：

```bash
curl -fsSL https://raw.githubusercontent.com/1812095643/ikun2api/main/deploy/migrate.sh | sudo bash
```

支持 **Linux systemd 与 Docker Compose 单实例部署**。先检查发布签名及数据库迁移兼容性，再停原应用、备份并切换；启动后核对业务数据，失败时按本次快照恢复。

迁入复用原 PostgreSQL、Redis、数据目录与数据卷，保留账号、用户余额、API Key、订阅、历史用量，以及 JWT、TOTP 和原有加密配置。

需要先做只读预检时：

```bash
curl -fsSL https://raw.githubusercontent.com/1812095643/ikun2api/main/deploy/migrate.sh | sudo bash -s -- --check
```

未知二开的数据库变更或迁移冲突会停止自动切换；自定义服务名、Compose 覆盖文件、备份位置及回退步骤见 [迁入与回退](deploy/MIGRATION.md)。

## 安装、更新与回退

新部署按 [安装说明](deploy/README.md) 选择 systemd、Docker Compose 或源码构建；已有 Sub2API 实例使用上面的带数据切换流程。

后续由管理员点击左上角版本号 → **检查更新** → **备份并一键更新**，无需自行合并源码。

- 只安装 IKUN 正式签名发布包，校验 **Ed25519 签名、SHA-256 与程序版本**，更新前执行兼容检查和完整备份。
- 保存独立的升级备份，支持回退；自动清理默认保留 **3 份**，可改为 1–30 份或关闭，恢复期间暂停清理。
- Compose 运行版本持久化到数据卷，旧镜像重启不会覆盖网页更新后的程序。首次从旧入口脚本升级时，仍需按版本说明更新一次应用镜像。
- 正式包由 **GitHub Actions** 构建，包含 Linux、macOS、Windows 二进制、完整源码及 Linux amd64 / arm64 容器和离线镜像。
