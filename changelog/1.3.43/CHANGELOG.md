# IKUN2api 1.3.43

## Claude 客户端隐私配置

- CC Switch 导入和「使用 Key」配置默认同时关闭 Claude Code 非必要流量与显式 OpenTelemetry 导出，覆盖 JSON、PowerShell、CMD、macOS/Linux 及复用 Claude 客户端的配置。
- 两个入口复用统一隐私配置，保留 CC Switch 中用户主动切换隐私选项的行为。

## 遥测字段与投递确认

- 遥测客户端类型调整为当前 CLI 配置对应的 `cli`，移除附加信息中的旧 `source=ikun2api_gateway` 标记。
- 保留对应上游账号的持久设备 ID、会话与账号关联、现有套餐设置、隐私过滤、单路错峰发送及实际请求摘要。
- 回执包含 `rejected_count` 时，校验其类型、范围及与 `accepted_count` 的总数一致性；矛盾、重复、非法或不完整回执不再记为投递成功。
- 兼容只返回接受数的旧回执，部分接受不自动重发整批，避免重复上报。

## 验证与升级

- 补充成功/失败、批次和定时发送、身份隔离及各平台配置生成回归；发布流水线加入「使用 Key」配置测试。
- 本版不新增数据库迁移，沿用现有签名更新、备份与重启流程。
- 配置变更需在客户端重新导入或更新配置并重启后生效；CLI 开关不代表 Claude Desktop 外层进程的全部网络行为已关闭。
