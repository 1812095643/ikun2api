# 1.5.3

- 新增管理员「记账收款」：充值时可选择记账跑付，支持部分收款、结清、经办人与往来流水；收款不重复增加余额。
- 新增「下游管理」：复用现有分组专属倍率，支持单个、批量调价、充值和用量统计，不划分代理等级、不预设倍率。
- 渠道模型价卡可单独设置是否对下游生效，实际扣费、额度预留和价格展示保持联动。
- OpenAI OAuth、API Key 账号可设置 Fast／Ultrafast 支持状态及计费倍率，支持按模型覆盖；输入、输出和缓存费用统一应用。
- OpenAI 分组和用户自己的 API Key 可设置强制 Fast／Ultrafast；分组策略优先，保留现有全局档位规则。
- 使用记录新增 Fast／Ultrafast 实际计费倍率标识，与扣费、账号计费紧凑纵向排列；历史记录不按当前配置重算。
- 请求时区默认跟随网关设置，可自动识别代理出口时区；系统设置的网关页可配置默认时区，账号保留手动覆盖。出口探测后台缓存，不阻塞模型转发。

## 升级

新增前向迁移 272、273，保留现有用户余额、分组倍率和历史用量。已有账号的手动时区仍可使用；选择「跟随网关设置」启用全局策略。服务器按原有后台更新流程操作即可。
