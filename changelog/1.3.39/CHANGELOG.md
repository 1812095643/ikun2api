# IKUN2api 1.3.39

- 运维监控设置新增“忽略客户端接入限制”开关，默认关闭。开启后不记录本地 Claude Code/Desktop 客户端准入拒绝的 403，实际访问限制仍生效，其他 403 不受影响。
- 上游 429 先记录账号限流状态；写入成功后从运维错误记录中排除。状态写入失败、未处理的限流及同一请求中的其他异常仍保留。
- Anthropic 未返回有效窗口重置时间时支持 `Retry-After` 秒数和 HTTP 日期，兼容小写响应头，避免把明确的恢复时间缩成默认 5 秒。
- 覆盖 HTTP、SSE、换号恢复和 WebSocket 多轮请求，处理凭据按请求和轮次隔离。
- 包含此前暂停发布的遥测修复：服务端摘要附加套餐默认 `pro`、官方后端类型 `firstParty` 和布尔值 `false` 的自定义地址标记；省略席位属性，阻止隧道、启动、恢复及未知诊断事件外发。
- 保留遥测后台开关、账号隔离、代理和单路错峰发送，并补充发布回归。

不新增数据库迁移，不清理历史错误。遥测属性是本项目重建摘要的扩展，不新增 OTel 导出通道；官方接收端对扩展属性的使用尚未验证。套餐默认值不参与权益或计费。
