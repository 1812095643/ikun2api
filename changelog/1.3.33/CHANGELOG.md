# IKUN2api 1.3.33

- 修复 Claude OAuth 会话携带已被上游拒绝的历史思考签名时，每一轮都先返回 400 再整流的问题。恢复成功后按用户、Key、账号、模型和会话记住旧块摘要，后续匹配时直接使用已验证的历史清理结果。
- 对齐官方 Claude Code 2.1.316 的明确签名错误恢复：清理旧思考块，保留当前思考模式、工具调用和普通消息；新生成的思考块及签名继续完整传递。
- 恢复记录只含摘要，在当前进程内有容量和有效期限制；失败重试不记忆，关闭签名整流后不使用记录。
- 新增不包含正文或原始签名的错误诊断，支持判断被拒绝的块经过网关转发时是否保持不变。
- 增加跨轮恢复、流式签名透传、会话隔离、过期与关闭开关回归，并纳入发布检查。
