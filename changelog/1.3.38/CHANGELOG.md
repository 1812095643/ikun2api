# IKUN2api 1.3.38

- 完善 Claude 服务端遥测摘要的附加属性：套餐默认 `pro`，官方出站类型使用 `firstParty`，自定义地址标记使用布尔值 `false`，省略席位属性。
- 构建与观测入口共同校验官方 HTTPS 主机、POST 和 Messages 路径；自定义上游不生成这份摘要，客户端不能覆盖服务端属性。
- 入口、批次合并和出站共用事件允许列表，阻止隧道、启动、恢复及未知诊断事件外发，拒绝重复 JSON 字段。
- 增加属性覆盖、诊断混批、账号隔离、串行发送与错峰回归，保留原始遥测丢弃和现有后台开关。

新增属性是本项目重建摘要的附加元数据扩展，不新增 OTel 导出通道；官方接收端对扩展属性的使用尚未验证。套餐默认值不参与权益或计费。本次不新增数据库迁移。
