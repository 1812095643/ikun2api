# 1.5.0

- 同步 Sub2API v0.2.21：合入 OpenAI 30m / 12h 缓存写入统计与计费、价格锁定、WS 续接、代理和流式兼容修复；保留 IKUN2api 的智能路由、通用订阅、账号隔离及原有协议处理。
- 修复无限画布图片已生成却显示失败：base64 结果在本地解码保存，独立工作室补齐 data/blob 读取权限，失败节点显示实际原因。
- 失效重登恢复账号行查看、补充与编辑登录资料、复制、单条重登和删除；资料读取沿用管理员二次验证。补齐负载系数、到期暂停、收敛档位、长上下文计费、模型映射和 WS 模式，读取迁移归档中尚未接回的旧模板设置。
- 新建 OpenAI OAuth 账号默认使用 WS 连接池，原生预热默认开启；账号或配置中已有的明确关闭选择继续保留。API Key 账号维持原设置。
- 修复工单轮询反复下载图片和滚动跳动；固定缩略图占位，收紧头部、消息与回复框，消息区根据窗口剩余高度展开。管理员和用户页面共用修复。

本版新增官方数据库索引及缓存写入字段迁移，前后端须配套更新。失效重登模板只用于新建账号；已有账号重新授权继续保留自己的分组、代理和请求设置。更新方式及签名校验沿用现有流程。
