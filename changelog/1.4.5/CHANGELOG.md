# IKUN2api 1.4.5

- 修复用户端号池只显示「本人近 7 天调用过的账号」的问题：现在按管理员配置的可见分组列出全部账号，从没发过请求的账号同样可见；使用记录与今日用量仍只统计当前用户本人。
- 修复合成虚拟账号额度「一眼假」的问题：5 小时与 7 天额度改为按真实时间窗口推进，重置时刻单调倒计时，不再是每次刷新都从当前时间往后滚。
- 合成账号的额度属性与 7 天伪名轮换解耦，跨轮换点不再整池跳变；最近使用时间落到带盐的粗粒度网格，并按账号序号分布在「刚用完 / 十几分钟前 / 两三小时前」三档，刷新不再漂移。
- 今日用量改为按本地时区零点归零并随当天时间推进，此前在 UTC 日界（北京时间 08:00）翻转。
- 合成账号的并发槽位与今日用量跟随真实号池的并发负载，没人使用时静下来；空闲时不会再出现「三小时没动却占着两个槽位」的矛盾。
- 修复 api_key 类型账号的 5 小时额度恒为 0 的问题：改用每日额度读数（已用 / 上限）计算，此前只识别 OAuth 的窗口字段。
- 号池概览卡片的账号数、活跃数与平台分布同步改为整池口径。
- 提示：号池设置中的可见分组当前为 `[1001]`（claude 满血，仅 3 个账号），想展示整池需在号池设置里清空或增选分组。
