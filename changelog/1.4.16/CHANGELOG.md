# 1.4.16

- 抽奖支持直接调整报名中的活动：可修改开奖时间、人数及参与条件，并增加奖项；保留活动与报名记录，新增版本冲突检查、事务签名校验和操作审计，保护已报名用户资格与已承诺奖项。
- 抽奖详情、编辑器与记录弹窗重新整理为紧凑概况和标签布局，同步优化手机端与明暗主题。
- 签到和盲盒管理拆为设置与账目标签；场次明细支持独立弹窗、分页、刷新和重试，优化奖池与榜单排版。
- 工单新增未读筛选及未读数量，管理员可按邮箱、用户名、用户 ID、工单 ID 或标题搜索；优化对话、回复和管理操作，修复切换工单的草稿串入与旧响应覆盖问题。

本版无新增数据库迁移。前后端需配套更新；更新方式与回退功能沿用现有流程。盲盒活动规则保持原有设置，本次仅调整页面与管理体验。
