# IKUN2api 1.3.44

## 实时号池界面与交互

- 移除重复介绍和大块头部区域，统一为站内紧凑标签栏、筛选工具栏、概览和表格；展示设置移入独立弹窗，使用记录的次要条件按需展开。
- 支持每 10/30/60 秒自动刷新与暂停，默认 30 秒；隐藏页面、离线时暂停，恢复后刷新，失败时退避，避免刷新请求堆叠。
- 修复快速切换账号或筛选时旧请求覆盖新数据、提前结束加载状态的问题；离开页面或关闭弹窗会取消相应请求。
- 读取失败明确显示“网络异常”和重试入口。后台刷新失败保留上次成功数据和时间，首屏失败不显示虚构的零值或空池。展示配置读取失败不再回退为不限分组。
- 保留既有账号展示、合成账号、费用统计与可调度口径；优化明暗主题、窄屏显示和额度单元格密度。

## 账号资料库自动对应

- 根据资料主邮箱自动匹配同平台的 OAuth 账号，忽略邮箱大小写及首尾空白，兼容 Claude/Anthropic 平台名称。
- 列表显示对应账号名称和 ID，可直接进入账号管理打开该账号。已有资料同样生效；匹配不到留空，同邮箱多个候选提示待确认，不自动选择。
- 排除 API Key、Setup Token 和已删除账号，不使用辅助邮箱或备注进行模糊匹配。
- 匹配在服务端执行，仅返回必要的账号引用；保留资料加密、敏感字段二次验证及既有手动关联字段。

- 本版不新增数据库迁移，沿用签名更新、自动备份和重启流程。
- 补充刷新竞态、网络异常、OAuth 匹配、账号跳转及真实 PostgreSQL 回归。
