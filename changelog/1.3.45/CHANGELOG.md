# IKUN2api 1.3.45

## 用户号池与分享

- 管理员可勾选多个用户可见分组，账号列表、窗口百分比、本人使用记录和分享页统一应用；兼容旧单分组设置，不固定某个分组。
- 用户号池采用独立页面，保留使用记录和 5h/7d 用量百分比，显示并发占用并复用账号管理窗口组件，移除金额、源账号 ID、完整分组归属等内部字段。后端使用字段白名单，逐账号明细入口关闭。
- 用户使用记录仅展示所选范围内本人请求的时间、脱敏账号、模型、类型和耗时。通用用户用量接口不再下发上游账号 ID 和名称快照，管理员记录保留原值。
- 增加无需登录的独立只读分享页。使用专用随机分享 token，数据库只保存摘要；有效期 30 天，重新生成或撤销会使旧链接失效，停用用户不可继续访问。
- 分享链接不使用登录 token 或 API Key；token 放入 URL fragment，避免进入访问日志和 Referer；分享接口不开放使用记录、凭据或写操作，并沿用限流。

## 资料库导入与保护开关

- 导入简化为粘贴后点击一次“确定导入”，后台自动识别并批量加密保存，默认跳过已有邮箱；解析不明确时指出行号并停止写入。
- 支持连续中文资料块、JSON、有/无表头 CSV/Excel，以及可明确识别的横线分隔格式；保留密码原始内容和批次幂等重试。
- 新增资料库专用两步验证保护开关，默认开启；关闭现有保护仍须通过当前验证。关闭后仍要求管理员网页登录，资料继续加密保存。

## 升级说明

- 新增 `265_pool_share_links.sql`，仅保存分享 token 摘要与失效时间，不修改现有账号、账单或资料库密文。
- 展示分组由管理员在实时号池 → 展示设置中勾选；未勾选表示不限制分组。
- 包含字段隔离、分组过滤、分享撤销/过期、导入幂等和保护开关回归。
