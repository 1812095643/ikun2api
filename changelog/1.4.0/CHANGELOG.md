# IKUN2api 1.4.0

## 使用记录

- 管理员和用户使用记录页新增“筛选设置”，可像列设置一样勾选显示或隐藏筛选框，并恢复默认显示。
- 默认保留现有筛选项和模型筛选。显示偏好按当前用户、管理员/用户页面和记录标签分别保存在浏览器中。
- 隐藏已选条件时清除对应筛选；通过链接、图表或排行应用的条件会自动显示，避免不可见条件影响查询。

## 实时号池

- 合成账号邮箱改为首字母大写、三个星号后带稳定生成的字母和数字后缀，保持现有轮换周期。
- 合成账号并发上限统一为 3，使用中并发保持在 0–3 范围内。登录页和分享直链使用同一份账号投影。

## 自动更新与备份

- 沿用 Sub2API 官方的检查发布、下载、校验、原子替换和显式重启流程，保留 IKUN2api 的签名校验、兼容检查、完整备份及失败恢复。
- 修复带时间戳的版本日志被误判为镜像变更、覆盖网页更新程序的问题；旧镜像不会静默覆盖更新的数据卷程序。
- 新镜像通过共用更新流程升级持久程序；检查失败且旧程序完整时继续使用旧程序。
- 新增备份自动清理设置，默认开启并保留 3 份，可调整为 1–30 份或关闭。升级恢复期间暂停清理，损坏及未完成备份保留。
- 每份新升级备份保存独立的程序、版本和校验信息，不再只有一份会被覆盖的旧程序。

## 部署

- 本版没有新增数据库迁移，沿用既有数据库、配置和数据卷。
- Docker 部署首次应用版本持久化修复时需要更新一次应用镜像，让新的入口脚本生效。保留原项目、数据库和数据卷，仅替换应用镜像。
- systemd 部署继续使用现有程序路径和 supervisor，可按原流程更新并重启。
