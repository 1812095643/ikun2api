# IKUN2api 1.3.41

## 更新体验

- 恢复 Sub2API 原有版本徽标、琥珀色新版本提示、更新日志与版本回退面板。
- 按原版流程执行「立即更新 → 立即重启」；移除升级前等待现有请求结束的阶段，重启直接退出并断开请求。
- 保留发行包签名、校验和、兼容性检查、程序与数据备份、启动失败恢复；不兼容的数据库版本仍阻止回退。
- 修正 Windows 上升级备份路径边界检查。

## 通用订阅与管理

- 套餐支持总额度、有效期及日/周/月上限，跨 Key 和已授权分组共用。
- 到期、额度用尽或达限立即停止，不提供普通余额接续。
- 支持在线购买、兑换码、管理员发放/调整、退款与历史记录；旧分组订阅保留存档并停用。
- Claude OAuth 账号新增模型白名单；新建、编辑、批量编辑与调度、计数、热身统一生效。
- 引导、教程、邮件、支付商品默认名称及多个页面统一复用站点名称。

## 升级与回退边界

- 升级前自动备份程序与数据。旧订阅用户、待付款订阅订单及未使用订阅码应先按原权益核对后切换；旧额度不会虚构折算为新额度。
- 版本回退保留数据兼容性检查。不能让不认识新财务账本的旧版本继续计费，也不会为回退直接删除新表或恢复成旧余额。
- 包含 Linux amd64/arm64、macOS amd64/arm64、Windows amd64、对应源码及多架构镜像附件；校验清单使用现有 Ed25519 密钥签名。
